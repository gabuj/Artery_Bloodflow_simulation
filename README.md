This repository contains code and meshes for simulating blood flow in arterial domains using Gridap, an open-source finite element library in Julia. This work was carried out as part of an internship project at **Universitat Politècnica de Catalunya**, with the broader goal of studying blood flow efficiency and geometry optimisation in pulmonary bifurcations.

## Repository Overview

The repository includes:

- Programs for solving the **incompressible Navier–Stokes** and **Stokes** equations on simplified and arterial geometries.
- Mesh generation scripts for converting surface meshes into Gridap-compatible volumetric meshes.
- Example models (2D and 3D test cases) used for validation.
- Initial artery meshes prepared for full blood flow simulation.
